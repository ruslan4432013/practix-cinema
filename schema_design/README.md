# Database Schema Design

Проектирование схемы базы данных PostgreSQL для хранения информации о фильмах.

## Описание

В данной директории содержится описание схемы данных (DDL), которая используется в проекте онлайн-кинотеатра. Схема включает в себя таблицы для фильмов, жанров и персон, а также связи между ними.

Основные принципы:
- Все таблицы находятся в схеме `content`.
- В качестве первичных ключей используются UUID.
- Настроены необходимые индексы для ускорения поиска.
- Установлены ограничения уникальности.

## Запуск локально

Для применения схемы к базе данных PostgreSQL:

1. Убедитесь, что у вас запущена база данных Postgres.
2. Выполните SQL-запросы из файла `movies_database.ddl`:
   ```bash
   psql -h localhost -U your_user -d your_db -f movies_database.ddl
   ```

## Переменные окружения

Для запуска скрипта через `psql` могут потребоваться стандартные переменные окружения Postgres:
- `PGHOST`
- `PGPORT`
- `PGDATABASE`
- `PGUSER`
- `PGPASSWORD`
