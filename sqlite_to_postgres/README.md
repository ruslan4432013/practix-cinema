# SQLite to Postgres Migrator

Скрипт для миграции исторических данных из SQLite в базу данных PostgreSQL.

## Описание

Этот инструмент предназначен для первоначального наполнения базы данных Postgres данными из существующего файла SQLite (`db.sqlite`).

Особенности:
- Использует `psycopg` для работы с Postgres и `sqlite3` для работы с SQLite.
- Использует `dataclasses` для валидации и типизации данных.
- Поддерживает пакетную загрузку данных (batch processing) для повышения производительности.
- Обрабатывает конфликты при вставке (DO NOTHING), что предотвращает дублирование при повторном запуске.

## Запуск локально

1. Убедитесь, что у вас установлены зависимости:
   ```bash
   pip install psycopg sqlite3
   ```
2. Настройте параметры подключения к Postgres в файле `constant.py` (словарь `dsl`).
3. Поместите файл `db.sqlite` в директорию `sqlite_to_postgres`.
4. Запустите миграцию:
   ```bash
   python -m sqlite_to_postgres.load_data
   ```

## Переменные окружения

В текущей реализации параметры подключения заданы в `sqlite_to_postgres/constant.py`. Для использования переменных окружения необходимо модифицировать скрипт или задать их в системе:
- `POSTGRES_DB`
- `POSTGRES_USER`
- `POSTGRES_PASSWORD`
- `POSTGRES_HOST`
- `POSTGRES_PORT`
